# 🎮 Tic Tac Toe

A responsive two-player Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 📌 About the Project

This project is a browser-based Tic Tac Toe game for two players.

Player X and Player O take turns placing their symbols on a 3×3 board. The first player to get three matching symbols in a row, column, or diagonal wins the round.

* ❌ Player X

## 🎯 Game Rules

Players take turns placing their symbols on the board.

The winning combinations are:

```text
X | X | X
---------
O |   | O
---------
  |   |
```

A player wins when they have three matching symbols:

* Horizontally
* Vertically
* Diagonally

If all nine cells are filled and nobody has three matching symbols, the round ends in a draw.

## 🎮 How to Play

1. Player X starts the game.
2. Click any empty cell.
3. Player O takes the next turn.
4. Continue taking turns.
5. The game automatically detects the winner or draw.
6. Use **Restart Round** to play another round.
7. Use **Reset Score** to clear the complete score.

## 📊 Scoreboard

The game keeps track of:

```text
Player X
Player O
Draws
```

Example:

```text
Player X: 2
Draws: 1
Player O: 3
```
